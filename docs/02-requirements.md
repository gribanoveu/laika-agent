# 2. Функциональные требования

Приоритеты: **Must** — без этого нет продукта; **Should** — важно, можно во вторую
волну; **Could** — polish. Колонка «Источник» показывает, откуда берётся реализация:
`перенос` (из Alfa Atlas почти как есть), `правка` (переносится с доработкой),
`заново` (в Atlas такого нет). Детали переноса — [04-reuse-map.md](04-reuse-map.md).

Блок **CA-10** (CLI) удалён вместе с решением делать продукт desktop-first. Нумерация
не сдвинута намеренно: на остальные ID уже ссылаются 04, 05 и 06.

---
